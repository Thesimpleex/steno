# Security

Steno handles your voice and text, so security reports are taken seriously.

Please report vulnerabilities **privately** via GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**. Please don't open a public issue for security problems.

You can expect an answer within a few days. Fixes are released as a new version on the
[releases page](https://github.com/Thesimpleex/steno/releases), with credit if you like.

Only the latest release is supported.
